8GB RAM minimum/16GB preferable,and at least12GB free for Python/dependencies/outputs.
These are setup recommendations,not benchmarks on a second laptop. NVIDIA GPU is optional.

Install64-bit Python3.14 (tested patch3.14.5); select the Python launcher during setup.
Python and dependency wheels are NOT bundled. Installation needs internet access or
separately obtained compatible wheels. Inference works offline after installation.

11. TROUBLESHOOTING
Missing package:use this project's .venv interpreter for both pip and Streamlit,then install
requirements-common-lock.txt and run pip check. Do not mix global Python and the project venv.
Python launcher absent:install the specified64-bit Python or use its full python.exe path for -m venv.
No matching distribution:check that Python is64-bit3.14 and the environment matches the tested versions.
Do not silently substitute new major versions; a second-device installation has not been tested here.
CUDA error:check torch.cuda.is_available();use CPU setup/CLI if necessary. Auto handles unavailable
CUDA and GPU-memory fallback; other driver errors remain visible rather than being hidden.
Port8501 occupied:replace --server.port 8501 with --server.port 8502 and open the matching URL.
Do not stop unrelated processes. Damaged upload:use an actual JPG/JPEG/PNG; extension/format,
20MiB limit and dimensions are validated. Model hash mismatch:re-extract a verified ZIP;
do not disable the integrity check. ZIP path too long:extract to a shorter writable folder.
Do not run the historic test-selection or training commands during the viva.
